## About this project
A design concept for a fictional brand (the business, names, prices and reviews are placeholder content), built to show my approach to **Professional services / legal** websites.

**What's inside:** Consultation request form above the fold, trust stats bar, practice areas grid, partner profiles.

## Tech
- Hand-coded HTML & CSS, no frameworks or page builders
- Fully responsive (desktop, tablet, phone)
- Single lightweight file that loads instantly
- Google Fonts
